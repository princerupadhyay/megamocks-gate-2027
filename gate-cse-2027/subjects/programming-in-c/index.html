Programming in C

First pass, ongoing

C is deceptive. I've written a lot of C-like code by now, but GATE's output-prediction questions on pointers and structures still catch me off guard more often than I'd like to admit.

Most of my time here is spent tracing through short, deliberately confusing programs by hand, on paper, without running them — since that's exactly what the exam asks for.

Topics I'm covering

  • Pointers & Memory
  • Arrays & Strings
  • Recursion
  • Structures & Unions
  • Output-Prediction Questions
  • Dynamic Memory Allocation

PYQ notes

Pointer-arithmetic output-prediction questions are the single type I still get wrong most consistently.
